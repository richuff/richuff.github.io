Uni-App

uni-app 是一个使用 Vue.js 开发所有前端应用的框架，开发者编写一套代码，可发布到 iOS、Android、Web（响应式）以及微信/支付宝/百度/头条/飞书/QQ/快手/钉钉/淘宝等小程序、快应用等多个平台。

其核心思想是**“一次开发，多端发布”**，让前端工程师用同一套 Vue 代码即可覆盖主流应用分发渠道，大幅降低跨端研发成本。

传统跨端方案往往需要为不同平台分别维护多套代码，而 uni-app 通过统一的 Vue 语法和编译器，解决了多端重复开发、维护困难的痛点。
DCloud UniApp 跨端框架 ## 1. 概述 uni-app 是一个使用 Vue.js 开发所有前端应用的框架。开发者编写一套代码，可发布到 iOS、Android、Web（响应式），以及各种小程序（微信/支付宝/百度/头条/飞书/QQ/快手/钉钉/淘宝）、快应用等多个平台。它将各端差异封装在编译器与运行时中，使业务代码保持统一。
**适用场景** uni-app 适合需要同时覆盖 App、H5 与多端小程序的团队，用一套 Vue 技术栈完成跨端交付。
## 2. 环境准备与官方资源 ### 2.1 下载 HBuilderX HBuilderX 是 DCloud 官方推荐的开发工具，内置 uni-app 编译与运行环境。 [HBuilderX-高效极客技巧 (dcloud.io)](https://dcloud.io/hbuilderx.html) ### 2.2 uni-app 官方文档 官方文档覆盖了组件、API、配置与多端差异说明，是日常开发的权威参考。 [uni-app官网 (dcloud.net.cn)](https://uniapp.dcloud.net.cn/resource.html) ### 2.3 unplugin-auto-import 自动导入插件 使用 `unplugin-auto-import` 可以在项目中自动导入 `vue` 与 `uni-app` 的 API，免去手动 `import`。 安装依赖： 
npm i unplugin-auto-import
创建 `vite.config.js` 文件： 
import uni from '@dcloudio/vite-plugin-uni';
import {defineConfig} from 'vite'
import AutoImport from 'unplugin-auto-import/vite'

export default defineConfig({
  plugins:[
    uni(),
    AutoImport({
      imports:[
        'vue',
        'uni-app'
      ] 
    })
  ]
})

<!-- 本示例未包含完整css，获取外链css请参考上文，在hello uni-app项目中查看 -->
<template>
  <view>
    <view class="uni-padding-wrap uni-common-mt">
      <view class="uni-title uni-common-mt">
        Vertical Scroll
        <text>\n纵向滚动</text>
      </view>
      <view>
        <scroll-view :scroll-top="scrollTop" scroll-y="true" class="scroll-Y" @scrolltoupper="upper"
          @scrolltolower="lower" @scroll="scroll">
          <view id="demo1" class="scroll-view-item uni-bg-red">A</view>
          <view id="demo2" class="scroll-view-item uni-bg-green">B</view>
          <view id="demo3" class="scroll-view-item uni-bg-blue">C</view>
        </scroll-view>
      </view>
      <view @tap="goTop" class="uni-link uni-center uni-common-mt">
        点击这里返回顶部
      </view>

      <view class="uni-title uni-common-mt">
        Horizontal Scroll
        <text>\n横向滚动</text>
      </view>
      <view>
        <scroll-view class="scroll-view_H" scroll-x="true" @scroll="scroll" scroll-left="120">
          <view id="demo1" class="scroll-view-item_H uni-bg-red">A</view>
          <view id="demo2" class="scroll-view-item_H uni-bg-green">B</view>
          <view id="demo3" class="scroll-view-item_H uni-bg-blue">C</view>
        </scroll-view>
      </view>
      <view class="uni-common-pb"></view>
    </view>
  </view>
</template>

<script>
  export default {
    data() {
      return {
        scrollTop: 0,
        old: {
          scrollTop: 0
        }
      }
    },
    methods: {
      upper: function(e) {
        console.log(e)
      },
      lower: function(e) {
        console.log(e)
      },
      scroll: function(e) {
        console.log(e)
        this.old.scrollTop = e.detail.scrollTop
      },
      goTop: function(e) {
        // 解决view层不同步的问题
        this.scrollTop = this.old.scrollTop
        this.$nextTick(function() {
          this.scrollTop = 0
        });
        uni.showToast({
          icon: "none",
          title: "纵向滚动 scrollTop 值已被修改为 0"
        })
      }
    }
  }
</script>
