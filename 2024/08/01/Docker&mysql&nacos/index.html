Docker&mysql&nacos

Docker 是一个旨在帮助开发人员构建、共享和运行现代应用程序的容器化平台，可在 Mac、Windows 或 Linux 上免费下载使用；本文在此基础上，进一步用 Docker 在 CentOS 8 虚拟机上部署 MySQL 数据库与 Nacos 服务，并通过自定义容器网络将它们连成一体。

核心思路是**以容器代替逐台手动安装**：把中间件标准化为可复用的镜像与一条条 docker run 命令，从而大幅降低环境搭建与排错的成本。

传统方式需要在每台物理机或虚拟机上手动安装并维护 MySQL、Nacos 等中间件；使用 Docker 后，只需几条命令即可拉起标准化容器，并将它们接入同一自定义网络实现互通。

实战部署 · CentOS 8 / Docker CE

1. 概述

本文是一份在 CentOS 8 虚拟机中基于 Docker 部署 MySQL 与 Nacos 的实战笔记，覆盖从虚拟机准备、Docker 安装、镜像加速器配置，到 MySQL 与 Nacos 容器化运行与访问的完整链路。

软件 / 组件 版本 / 说明
VMware Workstation Pro 虚拟机平台（用于承载 CentOS 8）
CentOS 8 操作系统镜像
Docker CE 容器引擎（来自阿里云镜像源）
MySQL 数据库，以容器方式部署，作为 Nacos 数据源
Nacos 镜像 nacos/nacos-server:v2.1.0-slim
Nginx 镜像 nginx，按需一并拉取

2. 准备虚拟机环境

2.1 下载 VMware Workstation

前往官方页面下载 VMware Workstation Pro：

下载 VMware Workstation Pro | CN

2.2 下载 CentOS 8 镜像

从阿里云开源镜像站获取 CentOS 8 安装包：

centos-8-isos-x86_64安装包下载_开源镜像站-阿里云 (aliyun.com)

2.3 安装虚拟机与系统初始化

安装虚拟机后，先执行系统更新：

yum update
**软件安装源与 DNS**：如果在安装过程中找不到软件安装源，可改用 `https://mirrors.aliyun.com/centos/8-stream/BaseOS/x86_64/os/`，并在网络配置中添加 DNS `8.8.8.8`。
**yum 元数据下载失败**：若执行 `yum update` 时出现下载元数据失败，可运行下面两条指令修复仓库地址，然后重新执行 `yum update`。 
sudo sed -i -e “s|mirrorlist=|#mirrorlist=|g” /etc/yum.repos.d/CentOS-*
sudo sed -i -e “s|#baseurl=http://mirror.centos.org|baseurl=http://vault.centos.org|g” /etc/yum.repos.d/CentOS-*

3. 安装 Docker

3.1 安装依赖与 Docker 引擎

yum - y install gcc
yum -y install gcc-c++
yum install -y yum-utils
yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
yum install docker-ce docker-ce-cli containerd.io docker-compose-plugin
systemctl start docker
systemctl enable docker

3.2 验证安装

docker version

4. 配置 Docker 镜像加速器

登录阿里云容器镜像服务获取专属加速器地址：

https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors?accounttraceid=54ebb47dd2134ed59f6d5d2b9215f808mvmm

将加速器地址写入 Docker 守护进程配置并重启生效：

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors":[加速器地址]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker

5. 拉取镜像

docker pull mysql
docker pull nginx

6. 配置 MySQL

6.1 创建网络

为后续容器互联创建自定义网络 richu：

docker network create richu

6.2 运行 MySQL 容器

docker run -d --name mysql -p 3306:3306 -e TZ=Asia/Shanghai -e MYSQL_ROOT_PASSWORD=123 -v /root/mysql/data:/var/lib/mysql -v /root/mysql/conf:/etc/mysql/conf.d -v /root/mysql/init:/docker-entrypoint-initdb.d --network richu mysql

7. 配置 Nacos

7.1 配置 MySQL 表

在 MySQL 中创建 Nacos 所需的数据库表，库名需与下文环境变量 MYSQL_SERVICE_DB_NAME 保持一致（即 nacos）。

7.2 配置环境变量文件

将 Nacos 的运行参数写入环境变量文件（如 ./nacos/custom.env）：

PREFER_HOST_MODE=hostname
MODE=standalone
SPRING_DATASOURCE_PLATFORM=mysql
MYSQL_SERVICE_HOST=192.168.3.133
MYSQL_SERVICE_DB_NAME=nacos
MYSQL_SERVICE_PORT=3306
MYSQL_SERVICE_USER=root
MYSQL_SERVICE_PASSWORD=123
MYSQL_SERVICE_DB_PARAM=characterEncoding=utf8&connectTimeout=1000&socketTimeout=3000&autoReconnect=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai

7.3 运行 Nacos 容器

docker run -d --name nacos --env-file ./nacos/custom.env -p 8848:8848 -p 9848:9848 -p 9849:9849 --restart=always nacos/nacos-server:v2.1.0-slim --network richu
**no DateSource Set 报错**：如果启动 Nacos 时出现 `no DateSource Set`，可加上 `--network` 参数，使其与 MySQL 处于同一自定义网络（如 `richu`）即可互通。

7.4 访问 Nacos 控制台

  • 访问地址：虚拟机 IP:8848/nacos
  • 登录账号：nacos
  • 登录密码：nacos

一句话总结：通过 Docker 在 CentOS 8 上将 MySQL 与 Nacos 以容器方式部署并接入同一自定义网络，即可用几条命令完成传统方式下繁琐的中间件安装与互联。
