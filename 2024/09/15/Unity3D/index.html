Unity

Unity 是一款跨平台游戏与交互式内容开发引擎，可用于在 20+ 个平台与设备上创建、发布并运营游戏、应用与各类体验。

其核心理念是 “一次开发、多平台部署”，通过统一的 C# 脚本 API 屏蔽不同平台差异，让开发者专注于游戏逻辑本身。

相比为不同平台分别编写原生代码的传统方式，Unity 提供统一编辑器与脚本接口，解决了跨平台重复开发与组件复用困难的痛点。

1. 概述

Unity 是一款跨平台游戏与交互式内容开发引擎，可在 20+ 个平台上创建、发布并运营游戏与应用。其核心理念是“一次开发、多平台部署”，通过统一的 C# 脚本 API 屏蔽不同平台差异。本文从 C# 脚本基础出发，系统梳理了物体、场景、物理、动画、UI 等核心模块，帮助开发者快速建立 Unity 开发的整体认知。

1.2 脚本生命周期

脚本从加载到销毁会按固定顺序调用以下方法：

方法 调用时机 说明
Awake 物体载入时 立即调用 1 次；常用于在游戏开始前进行初始化，可判断当前是否满足某种条件执行此脚本：this.enable = true;
OnEnable 激活后 只会调用一次
Start 开始时 调用一次，可设置初始值
FixedUpdate 固定频率 固定时间间隔调用
Update 每帧 每帧调用一次
LateUpdate Update 之后 适用于跟随逻辑
OnDisable 组件未激活 组件被禁用时调用
OnDestroy 销毁时 物体销毁时调用
OnApplicationQuit 程序结束 当前程序结束时调用
提示 生命周期方法由 Unity 引擎自动调用，无需手动 invoke；Awake 永远早于 Start，且同一帧内所有脚本的 Awake 先于所有脚本的 Start。

1.3 序列化特性

[SerializeField] 在编辑器中无法修改，在脚本内可修改，即序列化字段。

[SerializeField]
private int a = 100;

[HideInInspector] 在编辑器中无法显示。

[HideInInspector]
private int b;

[Range()] 限定数值范围。

[Range(0,100)]
private int c;
特性 作用
[SerializeField] 序列化字段，在 Inspector 中可见、可赋值，但脚本内仍可修改
[HideInInspector] 在 Inspector 中隐藏该字段
[Range(min,max)] 以滑块形式限定数值取值范围

public class AsyncTest : MonoBehaviour
{
    AsyncOperation operation;
    void Start()
    {
        StartCoroutine(loadScene());
    }

    //用携程来异步加载场景
    IEnumerator loadScene()
    {
        operation = SceneManager.LoadSceneAsync(1);
        //加载完场景不要跳转
        operation.allowSceneActivation = false;
        yield return operation;
    }
    float Timer = 0;
    void Update()
    {
        //输出加载进度0-0.9
        Debug.Log(operation.progress.ToString());
        Timer += Time.deltaTime;
        //达到5秒后跳转
        if (Timer > 5)
        {
            operation.allowSceneActivation = true;
        }
    }
}

private NavMeshAgent agent;
void Start()
{
    agent = GetComponent<NavMeshAgent>();
}

// Update is called once per frame
void Update()
{
    if (Input.GetMouseButtonDown(0))
    {
        //获取位置
        Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
        //射线信息类
        RaycastHit hit;
        if (Physics.Raycast(ray, out hit))
        {
            Vector3 point = hit.point;
            //该点为导航目标点
            agent.SetDestination(point);
        }
    }
}
