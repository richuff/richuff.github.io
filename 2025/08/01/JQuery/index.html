JQuery

jQuery 是一款快速、轻量且跨浏览器兼容的 JavaScript 库，核心理念为 Write Less, Do More（写更少代码，做更多事）。它以 CSS 选择器为基础，封装了 DOM 操作、事件处理、动画效果与 Ajax 交互等常用功能，提供简洁统一的 API，大幅降低原生 JS 编写成本与浏览器兼容负担。自 2006 年发布以来，它凭借链式调用、插件生态与高效开发体验广泛普及，至今仍在大量传统 Web 项目与快速原型开发中发挥作用。

其核心价值在于用**统一简洁的 API 屏蔽浏览器差异**，让开发者以极少的代码完成 DOM 操作、事件绑定与样式控制。

在传统原生 JavaScript 中，开发者需要为每个浏览器编写大量兼容代码、手动遍历 DOM 节点才能完成交互；jQuery 通过选择器与链式调用把这些繁琐操作收敛为几行可维护的代码，显著降低前端开发门槛。
jQuery 技术笔记

1. 概述

jQuery 是一款以 CSS 选择器为核心的 JavaScript 库，主打「写更少代码，做更多事」。它把 DOM 操作、事件处理、动画与 Ajax 等高频能力封装成统一 API，让前端交互开发更简洁、可维护。

1.1 核心特性

  • Write Less, Do More：以极少代码完成常见前端任务。
  • CSS 选择器驱动：以 $(css选择器) 选取元素，语法直观。
  • 跨浏览器兼容：屏蔽不同浏览器的 API 差异。
  • 链式调用：方法可连续调用，代码更紧凑。
  • 丰富的插件生态：可扩展性强，社区资料充足。

1.2 引入方式

可通过 npm 安装，也可在页面中直接以 <script> 引入：

npm i JQuery

// 页面中引入后，即可在 DOM 就绪后执行 jQuery 代码
$(function(){
    // jQuery 代码
});
**DOM 就绪** 使用 `$(function(){ ... })`（即 `$(document).ready()` 的简写）可确保 DOM 加载完成后再执行脚本，避免因元素未就绪导致的报错。

2.4 小练习

下面示例实现了一个菜单的悬停展开/收起效果：

$(function(){
    $(".main li").children("ul").hide()
    $(".main>li").mouseover(function(){
        $(this).children("ul").show()
    })
    $(".main li").mouseleave(function(){
        $(this).children("ul").hide()
    })
})

3. JQuery 入门使用

3.1 获取索引与事件绑定

通过 $(this).index() 可获取当前元素在其同级中的索引，常用于按钮组高亮切换：

<body>
    <button>test</button>
  <button>test</button>
  <button>test</button>
  <button>test</button>
  <button>test</button>
  <button>test</button>
  <button>test</button>
  </body>
<script>
    $(function(){
        $('button').click(function(){
            $(this).css('background', "pink");
            $(this).siblings("button").css('background', "");
            console.log($(this).index()) //打印出指定button的index
        });
    });
</script>

$(this).index() 获取索引

**高亮当前项** 在事件回调中使用 `$(this).siblings().css(...)` 可快速清除其他同级元素的样式，只保留当前项高亮。

3.2 修改样式 css 方法

css() 既可读取也可设置样式：

$(“div”).css(‘width’) 返回 div 的宽度

$(“div”).css(“height”,200) 将 height 设置为 200px

$(“div”).css({“height”,100,”width”,200}) 将 height 设置为 100px,width 设置为 200px

3.3 类操作

除直接改样式外，更推荐使用类名切换来控制样式：

1.添加类 $(“div”).addClass(‘current’)

2.移除类 $(‘div’).removeClass(‘current’)

3.切换类 $(‘div’).toggleClass(‘current’)

**选择器与样式分离** 直接写死的 `css()` 样式难以维护；建议把样式封装在 CSS 类中，用 `addClass / removeClass / toggleClass` 控制，便于统一调整与复用。

一句话总结：jQuery 以 CSS 选择器与链式调用封装 DOM、事件与样式操作，让开发者用极少的代码屏蔽浏览器差异、高效完成前端交互。
