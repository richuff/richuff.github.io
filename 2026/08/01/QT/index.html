QT

Qt 是一个跨平台的 C++ 图形用户界面应用程序框架。它为应用程序开发者提供建立图形界面所需的所有功能，完全面向对象、易于扩展，并支持真正的组件编程。

其核心在于**以一套代码同时构建多平台原生界面**，从而大幅降低跨平台桌面与嵌入式应用的开发成本。

相比为每个平台单独编写原生界面，Qt 用统一的 C++ API 屏蔽了平台差异，让开发者无需重复造轮子即可覆盖桌面与嵌入式场景。
Qt 跨平台 C++ 框架

1. 概述

Qt 作为企业级 GUI 开发框架，相较于传统“每个平台单独写一套界面”的方式，具备以下优势：

优势 说明
跨平台 几乎支持所有的平台
接口简单 容易上手，学习 Qt 框架对学习其他框架有参考意义
内存回收简化 一定程度上简化了内存回收机制
开发效率高 能够快速构建应用程序
社区氛围好 市场份额在缓慢上升
嵌入式开发 可以进行嵌入式开发
**适用场景** Qt 既适用于桌面端跨平台应用，也适用于嵌入式设备的图形界面开发。

2. 入门

2.1 main.cpp 文件

每个 Qt 应用程序都包含一个 main 函数作为入口，负责创建应用对象、构建界面并进入事件循环。

#include <QApplication>//包含应用程序头文件

//main函数，接收的参数
int main(int argc, char *argv[])
{
    QApplication a(argc, argv);
  
    MyWidget w;//创建应用对象
    
    w.show();     //展示对象
  resize(600,400); //重置窗口大小
    return a.exec(); //执行
}

2.2 QPushButton

按钮可通过两种方式创建：先 new 再设置父对象，或构造时直接指定父对象与文字。

//创建一个按钮
QPushButton* btn = new QPushButton;
//让按钮依附在窗口中
btn->setParent(this);
//设置文字
btn->setText("点我");

另一种创建方法

QPushButton* btn = new QPushButton("点我",this);
btn->move(100,100); //移动按钮到(100,100)

其他窗口方法

setWindowTitle("我是应用程序名"); //设置窗口标题

setFixedHeight(600);//设置固定高度
setFixedWidth(400); //设置固定宽度

setFixedSize(500,500); //宽  高 固定

2.3 信号和槽

信号（signal）表示各种事件，槽（slot）是响应信号的动作。例如按钮被点击后发出 clicked 信号，某对象接收到该信号后执行对应的槽函数。Qt 对象不会无故收到信号，必须通过 connect 建立发送者与接收者之间的连接。

QPushButton * quitBtn = new QPushButton("关闭窗口",this);

//信号的发送者 发送的信号(函数的地址) 接收者 处理的槽函数(函数的地址)
connect(quitBtn,&QPushButton::clicked,this,&MyWidget::close);

connect 函数的四个核心参数如下：

参数 说明
sender 信号发送者
signal 信号
receiver 信号接收者
slot 接收对象在接收到信号之后所需要调用的函数（槽函数）

2.4 自定义信号和槽

**定义信号发送方** 在 `signals:` 区域声明信号，信号只需声明、不需要实现。 
#include <QObject>

class Teacher : public QObject
{
    Q_OBJECT
public:
    explicit Teacher(QObject *parent = 0);

signals:
    void hungry(); //不需要实现
};
**定义信号接收方** 在 `public slots:` 区域声明并实现槽函数。 
#include <QObject>
#include <QDebug>

class Student : public QObject
{
    Q_OBJECT
public:
    explicit Student(QObject *parent = 0);
public slots:
    void treat(){ //需要实现
        qDebug() << "触发信号";
    }
};

建立连接并触发信号

connect(tc,&Teacher::hungry,sd,&Student::treat);
// 触发信号
emit tc->hungry();

2.5 解决槽的重载

当槽函数存在重载时（如带参 / 不带参），需要通过函数指针明确指定要连接的版本。

void Student::treat(){
    qDebug() << "test";
}

void Student::treat(QString foodName){
    qDebug() << foodName;
}

解决方式：使用函数指针区分重载

void (Teacher:: *teacherSinal)(QString) = &Teacher::hungry;
void (Student:: *studentSolt) (QString) = &Student::treat;

connect(tc,teacherSinal,sd,studentSolt);

QString 转 char*（避免输出带引号的字符串）

void Student::treat(QString foodName){
    qDebug() << foodName.toUtf8().data();
}

2.6 信号连接信号

除了“信号连接槽”，也支持“信号连接信号”：点击按钮触发的信号再转发为发送者的信号。

点击按钮，触发信号

QPushButton* btn = new QPushButton("click",this);
connect(btn,&QPushButton::clicked,this,&MyWidget::ClassOver);

void (Teacher:: *teacherSinal)(QString) = &Teacher::hungry;
void (Student:: *studentSolt) (QString) = &Student::treat;
connect(tc,teacherSinal,sd,studentSolt);

信号连接信号：点击按钮的信号触发发送者的信号

void (Teacher:: *teacherSinal)(void) = &Teacher::hungry;
void (Student:: *studentSolt) (void) = &Student::treat;
connect(tc,teacherSinal,sd,studentSolt);

connect(btn,&QPushButton::clicked,tc,teacherSinal);

2.7 Lambda 表达式

C++11 中的 Lambda 表达式用于定义匿名的函数对象，以简化编程工作。其基本构成分为四个部分：[局部变量捕获列表]、（函数参数）、函数额外属性设置 opt、函数返回值 ->retype、{函数主体}。

[capture](parameters) opt ->retType
{
    ……;
}
//调用
[=](){
    
}();

局部变量引入方式（捕获列表）如下：

捕获形式 说明
[ ] 不能访问外部函数体的任何局部变量
[a] 在函数体内部使用值传递的方式访问 a 变量
[&b] 在函数体内部使用引用传递的方式访问 b 变量
[=] 函数外的所有局部变量都通过值传递的方式使用，函数体内使用的是副本
[&] 引用的方式使用 lambda 表达式外部的所有变量
[=, &foo] foo 使用引用方式，其余是值传递的方式
[&, foo] foo 使用值传递方式，其余是引用传递的方式
[this] 在函数内部可以使用类的成员函数和成员变量，= 和 & 形式也都会默认引入
**注意** 引用方式捕获的对象可能存在“局部变量已释放而 lambda 尚未被调用”的情况，此时引用捕获进来的局部变量值不可预知。无特殊情况下建议使用 `[=](){}` 的形式。

2.8 opt 额外属性

最常用的是 mutable 声明，这部分可以省略。外部函数局部变量通过值传递引进来时，其默认是 const，不能修改该局部变量的拷贝，加上 mutable 即可修改。

int c = 0;
[ c ] () mutable {
    cout << c << endl;
    c = 10;
}();

lambda 表达式的返回值

// int --> 返回值的类型
int b = [c] () mutable -> int {
    cout << c << endl;
    c = 10;
    return 100;
    }();

2.9 槽函数使用 Lambda 表达式

以 QPushButton 点击事件为例，可直接将 Lambda 作为槽函数传入 connect。

connect(btn,&QPushButton::clicked,[=](){
        qDebug()<<"Clicked";
});

一句话总结：Qt 通过“信号与槽”机制与跨平台 C++ API，让开发者以一套代码构建多平台原生界面，并用 Lambda 等现代 C++ 特性简化事件处理逻辑。
