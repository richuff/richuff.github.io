钢琴谱

这里收录我整理与收集的钢琴谱。所有谱面以「扇形叠放」的形式汇成一张小预览图，点击任意一张即可查看或下载，下方列表也列出了全部曲目。

如何添加：把钢琴谱文件（PDF / 图片）放进 source/sheets/，预览图放进 source/images/sheets/，然后在 source/_data/sheets.yml 的 sheets 下追加一条（title / author / cover / file / tag）即可，页面会自动生成叠放预览与列表。
